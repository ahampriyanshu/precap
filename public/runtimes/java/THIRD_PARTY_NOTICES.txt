Asset hashes and exact source identities are recorded in manifest.json.
User programs compile and run inside a dedicated browser worker. There is no
server execution endpoint and no native Java compiler process in this path.
The compiler JAR URL includes its SHA-256 so future builds receive distinct
cache identities. The worker verifies those bytes before loading the JAR.
